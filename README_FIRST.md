# Boxpace Hospitality - Claude Handoff Package

This handoff is designed to be uploaded to Claude as a project bundle or as separate files.

## Upload order

1. Start a Claude chat/project and paste or upload `PROMPT_FOR_CLAUDE.md`.
2. Attach `BUSINESS_OVERVIEW.pdf` for the readable end-to-end business context.
3. Attach `Boxpace_Regional_Leads_Organized.xlsx` or `Boxpace_Karjat_Khopoli_Lonavala_100_Contacts.csv` if the work involves sales leads.

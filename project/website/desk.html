Calendar exchange

OTA calendars

Import each OTA’s calendar and publish one Boxpace availability calendar back to your OTA listings.

Calendar sync only: iCal carries booked or blocked dates. It does not sync nightly prices, guest details, changes to bookings, or live confirmations. Feed refresh speed depends on each OTA; keep watching the OTA calendars for conflicts.

How to connect

  1. In each OTA, export its calendar and paste that private HTTPS .ics link below.
  2. Save and sync. Copy the Boxpace calendar link and import it into each OTA listing.
  3. Repeat for every OTA and every property. Do not share calendar links publicly; they can reveal booking dates.

Boxpace refreshes imported calendars hourly and whenever you select Sync. The OTA controls how often it fetches the Boxpace link.
